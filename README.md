# 🔥 NEON SURVIVOR

スタイリッシュなネオン世界で、迫りくる敵をかき分けて生き残るトップダウン・サバイバルゲーム。

本作は **HTML ファイル（index.html）をクリックするだけで動作**する、  
シンプルかつ中毒性の高いサバイバル・ローグライクです。

## ✨ 特徴（ここが面白い！）

### ⚔️ 9種類の武器 × 3スロット制
最大3種類の武器を組み合わせて、自分だけのビルドを構築できます。

- **Plasma Gun**（自動射撃）  
- **Scatter Shot**（ショットガン）  
- **Nano Whip**（両側斬撃）  
- **Photon Blade**（周囲を回るプラズマ刃）  
- **Void Field**（継続ダメージフィールド）  
- **Railgun**（直線貫通レーザー）  
- **Plasma Grenade**（範囲爆発）  
- **Tesla Coil**（チェーン雷）  
- **Spider Mine**（自走地雷）

---

### 🎵 武器とBGMの相乗効果が気持ちいい
複数の武器を組み合わせることで、自分だけのビルドが完成。  
そのビルドに合わせて変化する **動的BGM** とシンクロすることで、  
プレイヤーは没入感溢れるサウンドスケープを体験できます。

## 武器育成・進化

開始武器はランダムな3候補から選択します。レベルアップでは所持武器の育成・共通強化・追加武器から選べ、武器は最大3種類、各Lv5まで育成できます。ボスを倒すと、Lv5の武器を1つ進化させられます。対象がない場合は通常の強化を選択します。

- 選択：クリック／タッチ、矢印・WASD＋Enter／Space、または1〜3。
- 再抽選：ボタンまたはR。1プレイ2回まで。開始武器・進化候補は再抽選対象外。
- 強化画面では戦闘・ウェーブ時間・遅延攻撃を停止します。
- 共通強化は原則5回、速度・特殊強化は3回まで。被ダメージ軽減は永続強化と合計で最大75%。
- 武器レベル・進化・再抽選は毎回リセットされます。既存のシャード・永続強化・ランキングは維持します。

通常敵は6ウェーブ周期の混成・装甲・高速・包囲・射撃・混成で編成されます。各ウェーブ冒頭5秒は出現頻度を25%下げ、5ウェーブごとにボスが登場します。無限生存形式です。

- 敵の移動速度は自機の基準速度（4.0）の85%が上限です。高速型（runner、ghost、bomber）だけは同速まで上がります。
- 最初のボス（Wave 5）はHPを80%に抑え、Wave 10以降は等倍です。
- 次のレベルに必要な経験値は、レベルごとに1.10倍で増えます。

### 開発時の回帰確認

Node.jsがある環境では、追加インストールなしで次を実行できます。ゲーム自体の起動にNode.jsは不要です。

```text
node --test tests/gameplay.test.cjs
```

テストは全9武器の強化、進化、報酬、経験値の連続選択、永続強化との合成、弾の貫通、30／60／120Hz相当の挙動と出現位置を確認します。描画・音声・人の操作による難易度評価は別途ブラウザで確認してください。

### 武器の進化演出と効果音

通常時は従来の見た目・SE・エフェクトを使い、全9武器の色・形・軌跡・光は進化した時だけ新しい演出に切り替わります。通常の武器レベルアップでは性能のみが上がり、専用の波紋や効果音は出ません。進化時には専用の波紋と効果音が出ます。演出によって当たり判定や威力は変わりません。

Nano Whipのみ、通常時も最新の扇状斬撃・命中エフェクトを使います。Lv1～5では同じ演出を維持し、SEは他の武器と同様に進化時だけ切り替わります。

進化後の攻撃音は低音・倍音・ノイズ・短いエコーを重ねます。進化後の連射時の発音数制限とコンプレッサーで過度な重なりを抑制します。外部の音源・画像・追加ライブラリは不要です。
